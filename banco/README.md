# Banco de dados

Firestore será o banco. Authentication gerencia as credenciais; senhas nunca devem ser armazenadas em documentos.

- `modelo-dados.md`: proposta inicial de coleções.
- `firestore.indexes.json`: índices versionados; inicialmente vazio.
- `exemplos/`: somente dados fictícios.
- Exportações e backups reais não devem entrar no Git.

A estrutura inicial não cria coleções nem altera um projeto Firebase.
